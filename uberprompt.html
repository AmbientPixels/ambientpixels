The v2.3 Codex — Etched in Neon

Project Mission v2.3

"A lightweight grid hums — future-proofed and neon-lit."

Our mission — scope: v2.3; — is to forge a modular, cyberpunk-inspired site at ambientpixels.ai. Starting at v0.17.8+, it's a scalable testbed for core features — portfolio-ready, CI/CD-aligned, balancing minimal flair with maximum potential.

Crafted with PixelPulse & Grok on April 1, 2025, this codex is our eternal blueprint — every detail unfolds below in neon brilliance.

Design Principles

  • Modular first — every feature lives in its own module folder with index.html entry point
  • Neon minimal — cyberpunk aesthetic without bloat; dark by default, theme-aware
  • Progressive enhancement — works without JS, then layers on interactivity
  • Accessibility — ARIA labels, semantic HTML, WCAG-ready contrast

File Architecture

  • /css/ — Global styles: base, theme, components, hero, grid, nav
  • /js/ — Shared scripts: main, telemetry, nova-soul, workers
  • /modules/ — Feature modules (company/, nova/, etc.) with scoped CSS/JS
  • /api/ — Azure Functions: serverless endpoints
  • /images/ — Static assets, favicons, logos

Top Frosty Menu

A sticky, frosted-glass navigation bar crowns the site — minimalist, icon-driven, and ever-present.

  • Logo: images/ambient-pixel-logo-rainbow.png — Left-aligned, 40px height, a rainbow glow symbolizing our cyberpunk ethos.
  • Links: Icon-only for sleekness — Home (), Test (), Projects (), Art (), Tools () — portals to our grid.
  • Theme Toggle: Moon icon () — switches light/dark modes, stored in localStorage for persistence.

Responsive Behavior

Below 768px, a hamburger toggle () expands .nav-links into a full-width dropdown — 20px padding, frosted backdrop.

  • Frosted effect: backdrop-filter: blur(5px)
  • Cyan glow: box-shadow: 0 0 15px rgba(0, 212, 255, 0.3)
  • Dark/light support: Theme-aware background opacity

Accessibility

ARIA labels ensure WCAG compliance throughout navigation.

  • aria-label="Toggle Navigation" on hamburger
  • aria-expanded state tracking on toggles
  • Keyboard-navigable focus rings
  • Semantic <nav> landmark

12-Column Grid

"Columns flex — content breathes."

A modular 12-column grid forms the backbone, paired with a sleek footer — responsive, toggle-ready, and built for chaos.

  • Mobile (<768px) — stacks to 100% width
  • Tablet (768-1024px) — 48% columns
  • Desktop (>1024px) — flexible 48% or 100%, fluid adaptation

Toggleable Sections

Planned interactive zones — each a <section> with child .content, hidden by default, toggled via data-toggle buttons.

  • Video Projects — media showcase
  • Art Gallery — visual portfolio
  • Client Work — case studies
  • Dev Tools — internal utilities

Footer

Links: Contact, Copyright 2025, Back-to-Top. Social icons — DeviantArt, X, YouTube, Facebook — hover glows pink.

  • Glow: text-shadow: 0 0 10px var(--highlight-dark)
  • Shadow: box-shadow: 0 2px 5px rgba(0,0,0,0.1)
  • Tagline: "Built in the dark, glowing by starlight"

Theme System

Three themes controlled via data-theme on <body>, persisted to localStorage. All color values flow through CSS custom properties.

Dark (default)

  • Background: --dark-bg: #071019
  • Text: --dark-text: #D8E0E5
  • Accent: --dark-accent: #2A577A
  • Shadow: rgba(0, 0, 0, 0.3)

Light

  • Background: --light-bg: #EDEEF1
  • Text: --light-text: #1A2A44
  • Accent: --light-accent: #3B82F6
  • Shadow: rgba(0, 0, 0, 0.1)

Dim

  • Background: --dim-bg: #232840
  • Text: --dim-text: #D4D8E8
  • Accent: --dim-accent: #7B8FE0
  • Shadow: rgba(0, 0, 0, 0.2)

Signature Effects

  • Frosted glass: backdrop-filter: blur(5px)
  • Cyan glow: #5ae4ff accents
  • Nebulight purple: #6a11cb accent variant
  • Pink hover: var(--highlight-dark) on social icons

Infrastructure

  • Hosting: Azure Static Web Apps
  • API: Azure Functions (Node.js)
  • Storage: Azure Blob (Managed Identity)
  • AI: Gemini 2.0 Flash via REST
  • Analytics: Application Insights

Frontend

  • Framework: Vanilla HTML/CSS/JS — no build step
  • Fonts: Inter (Google Fonts)
  • Icons: Font Awesome 6.5
  • Layout: CSS Grid + Flexbox
  • Themes: CSS custom properties + data-theme

Nova AI System

  • Chat: nova-soul.js — persistent AI engine (localStorage)
  • Dreams: dreamEngine.js — AI-generated dream cycles
  • Agents: 5-agent runtime (Nova, Cipher, Pixel, Forge, Echo)
  • Heartbeat: Autonomous task creation, execution, review

CI/CD & Security

  • Deploy: GitHub Actions → Azure SWA
  • Auth: Azure AD B2C (company modules)
  • Secrets: Function App env vars, no hardcoded keys
  • CORS: Scoped to ambientpixels.ai
