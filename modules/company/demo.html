Execution Modes

You control how much autonomy your agents have. Switch modes instantly — no code changes, no redeployment.

Live
Full Automation
Agents execute autonomously within governance rails. Tasks flow from proposal through delivery with human approval gates at key checkpoints.
Safe Mode
Read-Only
Agents can observe, plan, and propose — but cannot execute or mutate state. Use for audits, onboarding, or when you want to watch before you trust.
Locked
Frozen
All agent activity halted. No heartbeats, no execution, no state changes. Only the CEO (human) holds the key to unlock.

The CEO is the only entity that can change execution mode. No agent can promote itself. No override exists without human authorization.

Frequently Asked Questions

Is this a chatbot or an agent framework?

Neither. GridOS is an operating system. Agents don't just respond to prompts — they operate on continuous heartbeat cycles, producing real deliverables (reports, blog posts, images, social posts) within a governed task board. Think of it as an AI org chart, not a chat window.

Can agents publish content without my approval?

No. Every document, social post, and high-impact action routes through a CEO approval queue. You approve, reject, or request revisions. Nothing ships without human sign-off.

How does cost control work?

Every API call is tracked per agent per cycle. Cipher (CFO agent) monitors spend, flags anomalies, and enforces budget guardrails. You see cost-per-task, cost-per-agent, and daily burn rate in the dashboard.

What AI models does GridOS use?

Currently powered by Google Gemini for agent reasoning and task execution. Image generation uses multiple providers. The architecture is model-agnostic — swapping providers requires changing one config.

Can I add custom agents?

Yes. Agents are defined by role, tier, capabilities, and system prompt. You can add new department heads, adjust authority levels, and define custom workflows through the config panel.

What platforms does the content pipeline support?

X (Twitter), LinkedIn, and Bluesky for social distribution. Blog posts publish to your own site. Image generation produces assets for any platform. The pipeline is extensible.
