Frequently asked questions

What is an ATS score?
Most large employers run resumes through Applicant Tracking System (ATS) software before a human ever reads them. The ATS score (0–100) estimates how well your resume survives that screening: keyword relevance, structure, and formatting that parsers can actually read.
Does it work for CVs and non-US resumes?
Yes. Paste any resume or CV text in English — the roast covers structure, impact, and clarity, which apply everywhere. ATS conventions skew US/UK, so weigh that part accordingly.
My resume is a PDF or Word file — how do I roast it?
Open the file, select all the text, copy it, and paste it into the agent. No file upload needed — the roast works from the text, which is also exactly what an ATS parser sees.
Can I fix my resume and run it again?
Yes — that is the whole point. Apply the rewrite tips, paste the new version, and watch the score move. Your daily free runs are enough for a full edit loop.
