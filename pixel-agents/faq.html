Frequently Asked Questions

What are Pixel Agents?
Pixel Agents is an AI agent marketplace. Each agent is a specialized tool built for one task — analyzing websites, generating names, roasting resumes, checking trends, and more. Pick an agent, paste your input, get structured results in seconds.
How is this different from ChatGPT?
ChatGPT is a general-purpose chatbot. Pixel Agents are purpose-built — each one has a tuned prompt, structured output sections, and optional powers like web search or image generation. No prompt engineering needed. One click, real answers.
How many agents can I run per day?
Anonymous: 5 runs/day. Signed in: 25 runs/day. Pro subscribers: unlimited. Image-generation agents cost 2 runs.
How do I build my own agent?
Open Agent Forge (/agent-forge/). Name your agent, write a system prompt, define output sections (score, verdict, text, list, etc.), add powers, test it, and submit. The AI gatekeeper reviews quality, uniqueness, and safety automatically.
What happens during AI review?
Every submitted agent is scored 0-100 on quality, uniqueness, and safety by an AI gatekeeper. Score 70+ on all three = auto-approved and goes live immediately. Below 70 = forwarded to CEO review. Below 40 = rejected.
Can I edit my agent after it's live?
Yes. Cosmetic fields (tagline, icon, portrait, tier, temperature) can be changed freely. Core fields (name, category, prompts, output sections, powers) are locked and require re-review to change.
How does revenue share work?
40% of all Pro subscription revenue is split between creators each month based on how many runs your agents generated. Free creators keep 50% of their share, Pro creators keep 70%. Payouts via Stripe when you hit $25. Early creators benefit most as the pool grows.
What are agent tiers?
Tiers (Common, Uncommon, Rare, Epic, Legendary) are cosmetic labels that affect the card's visual style and glow effect. They don't change functionality — they're a way to brand your agent's rarity.
What powers can my agent have?
Three special capabilities: Web Search (searches the web before analysis), Fetch URL (reads actual page content for URL inputs), and Image Generation (generates an image via Gemini after analysis, costs 2x runs).
How do I contact support?
Visit the Contact page or email support through the contact form. We read every message.
