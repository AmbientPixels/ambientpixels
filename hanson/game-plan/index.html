💡 Quick Tips

  • 🔔 Alerts: Set reminders on any event — check the notification bell for upcoming alerts
  • ⏱️ Timer: Click the play button on any event to start tracking time
  • 📊 Dashboard: Click the Dashboard view to see all your stats and KPIs
  • Double-click any calendar day to quickly add an event
  • Use the search bar to find events by title, ID, or headline
