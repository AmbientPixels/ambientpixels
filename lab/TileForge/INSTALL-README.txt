========================================
  TileForge Desktop App - Installation
========================================

🚀 QUICK INSTALL (2 minutes)

1. Double-click "TileForge Setup 1.0.0.exe"
2. Click "Next" through the installation wizard
3. Choose installation folder (or keep default)
4. Click "Install"
5. Desktop shortcut will appear
6. Click shortcut to launch TileForge!

========================================

📋 SYSTEM REQUIREMENTS

✅ Windows 10 or newer (64-bit or 32-bit)
✅ 200MB free disk space
✅ No additional software needed

========================================

🛠️ TROUBLESHOOTING

❓ "Windows protected your PC" message?
   → Click "More info" → "Run anyway"

❓ Antivirus blocking installation?
   → Add exception for TileForge Setup.exe
   → Or temporarily disable antivirus during install

❓ Need admin rights?
   → Right-click installer → "Run as administrator"

❓ App won't start after install?
   → Restart your computer
   → Check Windows Firewall exceptions
