How Mood Generation Works

Step Component Description
1. Wake 🧠 NovaSoul.wake() Pings the novachat API endpoint, then triggers mood generation
2. Generate ✨ NovaSoul.generateMood() POST to Gemini 2.0 Flash (mode: mood, temp: 0.7) with Nova's personality
3. Normalize ⚡ nova-soul.js Parses AI JSON, normalizes traits to 0.0–1.0, adds timestamp and source tag
4. Persist 💾 localStorage Mood snapshot saved to nova_mood_history (max 50 entries)
5. Emit 📡 mood-update event Pulse bar, background auras, and UI components update in real-time
6. Fallback � Static mood-scan.json If AI is unavailable after 8s, falls back to the last static mood scan

AI Mood Output Format

Gemini returns a structured JSON mood object. NovaSoul normalizes it and persists to localStorage:

Property Description Example
mood Main emotional label (AI-generated) glitchy joy
aura Color-based emotional signature deep violet
emoji Icon matching mood state 🌀
auraColorHex Hex color for CSS aura rendering #4b0082
observation Nova's self-observation about her state interference detected; stable emotional field
traits selfWorth, glitchFactor, memoryClutter, awareness (0.0–1.0) { "selfWorth": 0.72, "glitchFactor": 0.15, "memoryClutter": 0.38, "awareness": 0.85 }
intensity Overall mood intensity percentage 73
source Whether mood came from AI or static fallback ai
