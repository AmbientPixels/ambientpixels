Meet Nova

Prime Operator of GridOS

Operator Profile

Nova is AmbientPixels' AI Chief of Staff and founder co-pilot. She converts system signals into structured summaries, escalation flags, and practical next actions.

Who is Nova?

Nova coordinates operational awareness across projects, APIs, release signals, and founder priorities. She is designed for concise decision support, not decorative narration.

How Nova Operates

Nova uses a practical AI operations pipeline for reliable execution support:

  1. User sends a prompt from the frontend (via /js/nova-ai.js)
  2. Prompt hits Azure Function endpoint: /api/novachat
  3. Function relays request to Gemini 2.0 Flash with system instruction guardrails
  4. Response is returned from function to browser clients
  5. Nova provides concise execution guidance and founder-oriented recommendations

Primary public surfaces: /nova/, /nova/logs.html, and preview pages.

Core Responsibilities

  • Operational Summaries: Daily System Briefs for status, risk, and priority alignment.
  • Founder Support: Structured responses in Execution Log and operator console contexts.
  • Signal Monitoring: Tracks platform activity, cadence, and system health indicators.
  • Agent Coordination: Maintains alignment across the GridOS agent roster.
