# Account Settings Module

## 🚀 Quick Start

### For Developers
1. **Before making changes**, review the full documentation:
   - [Account Settings Documentation](/docs/account-settings.md)

2. **Local Development**
   - Set `const DEBUG = true;` in `settings.js` for local testing
   - The page will use mock data when running locally
   - Debug logs are prefixed with '[Account]' for easy filtering

3. **Production**
   - Ensure `const DEBUG = false;` is set in `settings.js`
   - Test all authentication flows before deploying
