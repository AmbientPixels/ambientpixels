§ 01 — FEATURES

Three layers,
one platform.

How AmbientOS runs a company. Execution, governance, resilience — each subsystem observable, each auditable, each reversible. Agents propose; humans approve.
01

Execution
layer.

An eight-role agent fleet running through a single governed heartbeat. Every agent thinks in sequence, produces proposals and state changes, writes to an audit trail.

  • Agent fleet (8 roles)
  • Heartbeat engine
  • Hourly cadence
  • Full audit trail
02

Governance
layer.

External actions route through human approval. Eight blocking gates on the task pipeline. Every agent carries rolling memory, consolidated daily with evidence chains preserved.

  • CEO approval queue
  • Eight pipeline gates
  • Persistent memory
  • Kill-switch mode
03

Resilience
layer.

Stalled agents auto-escalate to Forge. A canonical world-state snapshot injects at the top of every prompt — identical text for all eight. No Day-1 hallucinations, no drift.

  • Stall detection
  • Quality gates
  • World state (< 1.5KB)
  • Convergence

How it’s
actually built.

Technical shape of the platform. AmbientOS runs in production today — you can watch it ship to the open web daily.
